Как пользоваться:
1. Перетащи файлы (или нажми чтобы выбрать)
2. Впиши нужный формат в поле: ico, png, jpg, pdf, wav, json и т.д.
3. Нажми «Конвертировать» → файлы скачаются по одному

Поддерживаемые конвертации:
• Изображения: PNG/JPG/WEBP/BMP/GIF/SVG ↔ PNG/JPG/WEBP/BMP/ICO
• Данные: JSON/CSV/TSV/XML/YAML ↔ между собой
• Текст: любой текст → TXT/MD/HTML/JSON/Base64
• Аудио: MP3/WAV/OGG/M4A/FLAC → WAV (и в MP3/OGG если браузер умеет)
• Видео: MP4/WEBM/MOV/MKV → WEBM/MP4
• JPG/PNG → PDF

Файлы никуда не отправляются — всё в браузере.
